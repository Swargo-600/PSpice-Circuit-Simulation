# Electrical Circuit Simulation Using PSpice

**Electrical Circuits Course — Individual Mini-Project**

## Project Overview

This project was completed individually as part of the Electrical Circuits course. It involves representing an electrical circuit using PSpice and examining the circuit design and simulation output.

## Objectives

- Design an electrical circuit using PSpice.
- Identify circuit components and their connections.
- Analyze voltage and current values shown in the simulation.
- Apply electrical circuit theory to simulation results.

## Tools Used

- **Software:** PSpice
- **File Format:** PSpice schematic (`.SCH`)

## Project Files

| File | Description |
